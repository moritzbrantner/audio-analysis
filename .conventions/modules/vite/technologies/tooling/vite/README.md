# Vite conventions

Vite is kept in a separate tooling branch because it is not inherently a React-only technology.

Rules in this directory use the `VITE-*` prefix and apply to Vite-specific development-server, build, plugin, environment, alias, and bundling conventions.

A React + Vite project combines this scope with the applicable TypeScript/React scope through a profile or repository-specific configuration rather than nesting Vite below React.
