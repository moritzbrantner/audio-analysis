# audio-analysis-processing-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `audio-analysis-processing`.

Run the server:

```bash
cargo run -p audio-analysis-processing-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/audio-analysis-processing-app dev
```
