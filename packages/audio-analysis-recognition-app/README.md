# audio-analysis-recognition-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `audio-analysis-recognition`.

Run the server:

```bash
cargo run -p audio-analysis-recognition-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/audio-analysis-recognition-app dev
```
