# audio-analysis-synthesis-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `audio-analysis-synthesis`.

Run the server:

```bash
cargo run -p audio-analysis-synthesis-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/audio-analysis-synthesis-app dev
```
