# audio-analysis-transcription-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `audio-analysis-transcription`.

Run the server:

```bash
cargo run -p audio-analysis-transcription-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/audio-analysis-transcription-app dev
```
